상품 1008개 / 연결된 사진 918개 / 사진 준비중 90개
엑셀 대표이미지 값 1 → images/1.png 방식으로 연결했습니다.
상품번호는 기존 찜 데이터와 섞이지 않도록 내부적으로 X를 붙였습니다.
사진과 가격이 빈 상품은 각각 사진 준비중, 가격문의로 표시됩니다.
가격 숫자는 단위를 변환하지 않고 원본 소수점 그대로 표시합니다.
판매상태가 비어 있는 2개는 상태 미입력으로 표시합니다.
확인이 필요한 상품은 연결_확인목록.csv에 있습니다.

적용 방법
압축을 풀고 폴더 안의 index.html, style.css, script.js, products.json, settings.json과 images 폴더를 GitHub 저장소 최상위에 업로드하세요.
압축 파일 자체가 아닌 압축을 푼 파일들을 올려야 합니다.
기존 images 폴더가 있으면 삭제하지 말고 새 사진을 추가하세요.
배너 이미지는 사용하지 않습니다.

엑셀을 나중에 수정해도 사이트에 자동 반영되지는 않습니다. products.json으로 다시 변환해야 합니다.

엑셀 연결 정보가 없는 사진 161.png, 903.png, 943.png도 images 폴더에 보관했습니다. 임의로 상품에 연결하지 않았습니다.
