당그니네 밭 러빗 PICK 배지 추가 (이전 당그니 PICK 최신 수정본 기준)

1. GitHub 저장소의 script.js 파일을 이 파일로 덮어쓰고 Commit changes
2. 사이트에서 Ctrl+Shift+R 새로고침
3. 구글 스프레드시트 상품입력 > 태그 열에 '러빗 PICK' 입력
   (러빗 픽 / 러빗픽도 인식)
4. 함께 표시하려면 '당그니 픽|러빗 PICK' 입력

표시: 상품 사진 왼쪽 아래, 당그니 PICK 옆에 라벤더색 '🐰 러빗 PICK'
당그니 PICK 기존 디자인/크기/위치 유지, NEW/HOT/RELIC 및 정렬 로직 유지.
참고: GitHub의 실제 현재 파일과 비교한 것은 아니므로 적용 전에 기존 script.js를 백업하세요.
