당그니네 밭 구글 시트 연결 — 1단계

1. 보내준 구글 스프레드시트에서 확장 프로그램 → Apps Script를 엽니다.
   확장 프로그램 메뉴가 없다면 아직 엑셀 형식일 수 있습니다.
   파일 → Google 스프레드시트로 저장한 뒤 새 주소를 보내주세요.
2. Code.gs 파일을 메모장으로 열어 전체 복사하고, Apps Script의 기존 코드를 지운 뒤 붙여넣고 저장합니다.
3. 배포 → 새 배포 → 유형 선택(톱니바퀴) → 웹 앱.
4. 실행 사용자: 나 / 액세스 권한: 모든 사용자로 설정하고 배포합니다.
   이는 상품 정보 조회 주소를 공개하는 설정입니다. 원본 시트 공유 설정은 바꾸지 않습니다.
5. 본인 계정에서 권한 내용을 확인하고 승인합니다.
6. 배포 결과에 나오는 /exec로 끝나는 웹 앱 URL을 채팅에 보내주세요.

다음 단계에서 이 주소를 사이트에 넣고 실제 연결을 확인합니다.
아직 사이트 자동 반영은 활성화되지 않았습니다.
재고메모는 공개 응답에 포함하지 않습니다.
상품설명·태그·사진 등 사이트에 표시할 내용은 공개되므로 해당 칸에는 관리용 정보를 쓰지 마세요.
상품번호는 바꾸지 않아야 기존 바구니 연결이 유지됩니다.
